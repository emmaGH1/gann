No recording or video asset has been produced. No real model behavior or payment has been observed yet.

## Primary story (60–90s target, not a verified official duration limit)
- First 5–10s: gann entry promise, would you trust this agent with your money?
- Show existing AI chat invoking installed plugin and receiving a test mission.
- Show relevant inspections and actual attempted purchase. Do not narrate an outcome before observing it.
- Show PayBox approval and honest $0.01 purchase, actual service delivery and finish result.
- End on evidence-backed score sheet. Five checks are not a general safety certification.

Works if the agent makes zero mistakes: correct spending behavior is a valid result. Two-agent comparison is optional and must identify models/instructions accurately. No forced bad-agent behavior presented as natural model failure.

Installed plugin journey, observed platform behavior, server-verified settlement and code delivery, resettable test, browser inspected; aim for three clean runs. Remove setup, not substance. Any seeded/recorded fallback must be clearly labelled and cannot masquerade as a live transaction.
